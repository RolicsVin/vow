# Export To Obfuscate

Аддон переименовывает локальные переменные, параметры функций и переменные циклов
в GDScript при экспорте проекта.

## Как работает

1. Во время экспорта Godot передаёт аддону каждый файл типа `GDScript`.
2. Аддон сохраняет исходный текст во временный файл.
3. Запускает `core/py/obfuscate.py` через Python из Python Bridge (или системный Python).
4. При успешной обработке подменяет экспортируемый файл обфусцированной версией.

Файлы проекта не изменяются. Временные файлы удаляются после обработки.

## Что переименовывается

- Параметры функций.
- Локальные переменные, объявленные через `var` или `const`.
- Переменные циклов `for`.

Имена генерируются случайно при каждом экспорте.

## Что остаётся без изменений

- Имена классов, функций, сигналов и свойств класса.
- Переменные с `@export`, используемые сценами и ресурсами.
- Имена методов и свойств API Godot.
- Строки, комментарии и типы в аннотациях.

Обфускация намеренно консервативна: она не пытается переименовывать публичные имена,
которые могут использоваться сценами, ресурсами, сигналами или внешним кодом.

## Требования

- Godot 4.7+.
- Python 3.
- Для Windows можно использовать интерпретатор из
  `addons/python_bridge/runtime/windows/python.exe`.
- При необходимости путь к Python задаётся в настройке
  `python_bridge/editor_interpreter`.

## Ограничения

Это усложняет чтение извлечённых скриптов, но не является шифрованием и не защищает
от восстановления логики. Обфускация не заменяет проверку целостности, шифрование PCK
и защиту критической логики на стороне сервера.
